Advanced paths stores local paths only. Auto configure reviews the fixed app-managed layout; neither action contacts a TV.

                    
Register local webOS target changes only the vendor CLI target list on this computer. It does not pair with, validate, or operate a TV.

                    
Validate a saved LG profile only after an explicitly approved live preflight. If the TV shows a pairing prompt, approve it manually and do not dismiss or retry it automatically.
