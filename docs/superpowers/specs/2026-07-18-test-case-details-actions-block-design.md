# Test Case Details Actions Block

## Goal

Apply the same visual treatment to the Test Case Details modal's Action field so the complete ordered action list appears in one slightly darker value block.

## Design

Reuse the existing `.action-preview` ordered list generated by the renderer. Add the same block surface used by other detail values: block display, padding, border, rounded corners, and a slightly darker background. Keep the list numbering, monospace action text, whitespace preservation, and wrapping unchanged.

No renderer, IPC, data-model, or modal-layout changes are needed.

## Verification

Add a stylesheet contract test for the `.action-preview` block properties, then run the full unit suite, renderer syntax check, and `git diff --check`.
