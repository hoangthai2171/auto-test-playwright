# Test Case Details Value Blocks

## Goal

Improve scanability in the Test Case Details modal by placing every rendered field value in its own slightly darker visual block while keeping the existing labels and data rendering unchanged.

## Design

Reuse the existing `.test-case-detail-row` markup generated by the renderer. Style the value element in each row as a block with a darker background, subtle border, padding, and rounded corners. Preserve whitespace and wrapping so descriptions, metadata, and action previews remain readable without horizontal overflow.

No renderer, IPC, or data-model changes are needed. The existing modal layout and scrolling behavior remain unchanged.

## Verification

Add a renderer stylesheet contract test that checks the detail-value block has the required display, background, border, padding, and wrapping properties. Run the full unit suite and `git diff --check`.
